# 앱 업데이트 알림

Android 1.9부터 실행 및 앱 복귀 시, 그리고 활성 화면에서 1분 간격으로 서버의 `/app-release.json`을 확인한다.
설치된 버전 코드보다 배포 버전 코드가 크면 업데이트 안내를 표시하고, 확인 시 Play 스토어를 연다.
나중에 선택하면 해당 실행 중 같은 버전 알림을 반복하지 않는다. 사진 업로드 및 열린 창은 방해하지 않는다.

운영 서버의 `public/app-release.json`에는 실제로 Google Play에 배포된 버전만 기록한다.
현재 값은 내부 테스트에 게시된 1.16(코드 17)이다. 새 버전을 게시한 뒤 설치 가능 상태를 확인하고 값을 변경한다.
코드만 먼저 올리면 아직 설치할 수 없는 업데이트를 안내하게 된다.

운영 서버에 이 JSON 파일과 서버 변경사항을 반영해야 한다. 기존 1.8은 수동 업데이트가 필요하다.
내부 테스트 사용자는 Play 스토어에서 테스터로 등록된 Google 계정을 사용해야 한다.
